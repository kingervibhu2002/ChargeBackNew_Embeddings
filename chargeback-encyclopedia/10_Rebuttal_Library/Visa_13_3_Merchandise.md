# Rebuttal Template: Visa Reason Code 13.3 — Merchandise Not As Described or Defective

## About This Reason Code

Visa Reason Code 13.3 is filed when a cardholder claims that the goods received were materially different from what was advertised or were defective. This is a quality-of-goods dispute. To win, you must demonstrate that the product shipped matches the product described at the time of sale, and/or that the cardholder did not follow the proper return process before filing a chargeback. This reason code is frequently used for friendly fraud — accepting a product but disputing it as defective to avoid paying.

---

## Pre-Submission Checklist

- [ ] Screenshot of the original product listing at time of sale (description, photos, specifications)
- [ ] Photograph or documentation of the item actually shipped
- [ ] Return policy displayed at checkout or in confirmation email
- [ ] Evidence that cardholder did not attempt a return before filing the chargeback
- [ ] Customer service communications (if cardholder complained before dispute)
- [ ] Packing records showing correct item was shipped
- [ ] Any quality control inspection record
- [ ] Authorization record for the transaction

## Merchant Notes

- Use the Wayback Machine (web.archive.org) if you updated your listing after the sale date, as issuers may question whether the description shown is the one the cardholder saw at purchase time. Capture dated screenshots of all live listings at the time of major sales campaigns.
- If the cardholder claims an item is defective, ask whether the cardholder contacted you about the defect before the chargeback. If not, note the absence of any complaint. Most defective claims that skip merchant contact are friendly fraud.
- For custom or handmade goods, include a description of your production process and any photos or records from production showing the item matched specifications.
- 13.3 is often used when the real issue is buyer's remorse. A clearly disclosed no-refund or all-sales-final policy, paired with a description that matches what was delivered, is a strong defense.
